# 4.5 The chain rule
## Case one: Single variable
Given $z=f(x(t), y(t))$ then the derivative with respect to t is:

$$
\frac{dz}{dt}= \frac{ \partial f }{ \partial x } \cdot \frac{ \partial t }{ \partial x } + \frac{ \partial f }{ \partial y } \cdot\frac{ \partial y }{ \partial t }  
$$
## Case 2:
Given $z=f(x(u, v),y(u, v))$ 
$$
\frac{ \partial z }{ \partial u } = \frac{ \partial z }{ \partial x } \cdot \frac{ \partial x }{ \partial u }+\frac{ \partial z }{ \partial y } \cdot \frac{ \partial y }{ \partial u } 
$$
Which you might notice is just the same thing as above, but i substituted $t$ for $u$.
Furthermore, if we want $\frac{ \partial z }{ \partial v }$ then we just substitute $t$ for $v$.


> [!Tip] Fun Fact
> So there is no "normal derivative" for a function like the above. Instead, you can only have partial derivatives.
> But what about the function from Case one? Well, it would actually trace out a line in 3D space. In that case you can see how there is a single vector that represents where the curve is going, and that vector is its definitive derivative.
> Otherwise, you have a surface, and the derivative of that surface, well, that doesnt actually mean much.
